8. PRODUCTION PICKING / AIM
==================================================

Screen XY alone is not a valid spatial target.

For spatial worlds:

1. construct the camera/picking ray,
2. intersect visible physical candidate faces and actor proxies,
3. choose the nearest physically visible valid hit,
4. if no valid hit exists, intersect the defined aim plane through the player's
   eye,
5. derive world aim/light direction from that world point,
6. feed resulting gameplay input into existing fixed-tick input handling.

Never:
- choose an arbitrary highest floor
- choose a hidden entity
- select through an intact slab because cutaway made it transparent
- use screen distance as physical interaction range
- let DPR/resolution/zoom change physical reach

Flat mode retains accepted flat aim behavior.
