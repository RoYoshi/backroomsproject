## Data the new code reads

Only the moving body's own state and its own route: `e.path` (its waypoints, their link and cell class), `e.x`, `e.y`, `e.ang`, `e.speed`,
`e.rc`, `e.mode`, and the level's shape (`geo.lineClear`).  No player, no perception, no randomness.  Its cost: one angle test per follow
call, and - only when the aim swings back more than 57 degrees - a few more arithmetic tests and at most one `lineClear` and one re-entry of
`follow()` (guarded against a second).
