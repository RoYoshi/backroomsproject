1. The compiled client's side of the window contracts (FINDINGS M-005)
   The page's classic scripts and the compiled client talk through window. Since C4 the client is TypeScript and declares every window
   member it uses in src/core/client/game/client/contracts.d.ts (its type, the script that defines it, the lineage step), so TypeScript
   checks each use at every build. dev/tools/checks/window_contract.js (TypeScript 6.0.3, as the parts and modules checks) holds those
   declarations to the code on both sides:
     1. every window member the client's source reads or writes is declared, and window is never cast to escape the declarations;
     2. every declaration is used;
     3. no member the client reads is left undefined by the page's scripts;
     4. every script that writes a member the client uses is named in the member's declaration, the first one named writing it;
     5. the built bundle (public/assets/index-DKbV5Nv9.js) reaches the same window names as its source.
   (A script's writes and reads are counted as docs.js counts them for CONTRACTS.md; the client's from its TypeScript.)
   - First run: rule 4 found that assets/shadows-2d.js (BR-RoLE) writes window.__mp too - it wraps the per-frame hook mp.js defines, to
     draw its shadows after it - and the declaration named only mp.js (FINDINGS M-035, as on B++). Its comment now names both; the
     declarations are comments and types, and the built bundle is C4c's byte for byte (SHA-256 9624ba47...).
   - On this tree (window_contract.json): 35 members declared and used, every rule holds.
   - --mutants 1 (window_contract_mutants.json): 8 breaks, each refused by its rule and by nothing the control has: an undeclared member
     read; a declaration nobody uses; a read of a name no page script writes; a declaration that loses its script; a page script that
     starts writing a member the client reads (hud.js writing __mv); the built bundle reaching a name its source does not; the built
     bundle no longer writing a member its source writes (__lastCause); window cast to any. The control PASS.
