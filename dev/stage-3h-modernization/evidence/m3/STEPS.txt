## the checker (dev/tools/checks/parts.js; a new gate step, "parts")
  Each part of a built output begins with a "/** @part <output> - <owner>: <what it is>" header that the build removes. It lists what the
  part provides to the other parts of its script, what it uses of theirs, and which of their bindings it writes. The checker assembles each
  output as the build does, finds the shared closure (the function with the largest body: an IIFE, ai.js's UMD factory, createSim) with
  TypeScript's parser, gives each statement to the part it lies in (a statement may not straddle two parts), and resolves every name with
  TypeScript's checker, so a local that shadows a closure name is not counted.
node dev/stage-3h-modernization/tools/m3_parts_mutants.js --work $SP/em2/work/m3_mut --out parts_mutants.json            exit 0
  the untouched copy passes; refused: a provides list missing a name, a uses list with an extra one, a writes list missing one, a header
  naming another output, a part without its header, a statement cut in two by a split (the output's bytes unchanged)
