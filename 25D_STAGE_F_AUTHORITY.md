# Stage F authority boundary

The accepted architecture and F5 recovery prompt remain authoritative. The retained
hybrid player motor predicts locally and owns stamina. This is not a fully
server-input-authoritative locomotion conversion.

The server owns entities, capture/death/lifecycle, items, permissions, authenticated
teleports, canonical Z/support and physical transition time. Socket callbacks only
queue movement claims. Fixed ticks apply bounded validated state; historical
validation never reruns AI. Full collider/support/clearance is checked. Server ticks
earn movement credit; the preserved distance budget caps at 540 units with 28-unit
slack recorded as debt. Stale sequence/world/life/ACK, malformed values and impossible
motion cannot choose another support or alter authoritative lifecycle.

Unsupported falls, assisted steps, canonical vaults/traversal and capture continue
on fixed server ticks without victim packets. At ownership transfer, queued old
predictions are cleared; later packets cannot advance the same transition twice.
At landing the authoritative correction permits the client to rebase. Quiet gait
claims cannot suppress the noise floor from accepted physical speed. Permission
checks precede admin teleport; destinations must fit and identify real support.

The F5 vault packet-bound fix admits finite predicted substeps within the existing
wire envelope so that the real canonical vault start can be validated. It does not
accept 471-unit/s ordinary ground speed; focused attacks prove that distinction.
No locked architecture amendment, motor replacement or transport replacement was
needed. Snapshot/physics schedules are unchanged.

Flat Level 0 remains on retained movement/AI/death paths. Future spatial corpse,
independent equipment and always-authoritative aftermath are not implemented here.
Production spatial visual integration remains deferred. Human judgment of feel,
fairness, readability and dread remains a separate gate. Do not begin Stage G.
